# 多语言资源说明

右上角可切换简体中文、繁体中文、日语和韩语。选择保存在当前设备的浏览器本地存储中；切换语言无需翻译接口，也不需要账号。宝可梦、招式、特性、道具和性格名称随安装包与网页一起提供，可离线使用。搜索仍支持原有中文、拼音、英文和自定义别称，也支持新增语言的名称。

名称数据由 [PokéAPI 的多语言 CSV](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)按项目现有图鉴生成。来源许可见部署文件中的 `pokeapi-license.txt`。繁体中文的动态文字使用本地 [opencc-js](https://github.com/nk2028/opencc-js) 转换；相关许可见 `opencc-js-license.txt`、`opencc-js-third-party-licenses.md` 和 `opencc-js-apache-2.0.txt`。日语和韩语界面文案保存在项目代码中，运行时不请求 Google 翻译或其他翻译服务。

PokéAPI 尚无《宝可梦冠军》新增特性与部分新形态的官方多语言记录。此类名称已在本项目补充可辨认的本地译名，尤其保留超级进化 X/Y/Z 及地区形态的区别；这些补充译名应在游戏正式译名发布后核对。用户自己输入的队伍名和别称不会改写到保存数据中。
