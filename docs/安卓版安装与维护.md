# PMC 安卓离线版

版本：1.1.0。应用名：PMC。包名：cn.pmc.calculator。

## 安装和使用

把 `output/android/PMC-1.1.0-android.apk` 发到安卓手机，打开文件后按系统提示安装。只给你用于接收安装包的应用开启“允许安装未知应用”；安装后可以关闭该权限。不要关闭手机的安全扫描。

已有旧版时直接覆盖安装，不要先卸载。1.1.0 沿用原签名，已在模拟器验证从 1.0.0 升级后配置、场景及自定义背景保留；仍建议先做一次完整导出。

设置新增“APP 屏幕方向”：默认跟随手机旋转，也可固定横屏或竖屏。友情防守保留开关，选择具有该特性的队友会自动勾选；手动关闭后，在更换宝可梦、特性或在场状态时重新自动判断。旧场景会提醒核对威吓触发前的能力等级，不会自动重置原配置。

要求 Android 8.0 或更新系统，以及 Android System WebView 107 或更新内核。APK 不适用于 iPhone，也不适用于不能运行安卓 APK 的系统。部分厂商可能限制外部安装。

安装包内置计算器、默认背景、洛托姆图标和宝可梦图片。计算不需要联网。讨论频道及其他外部链接会打开 QQ 或浏览器，这些链接需要网络。

网页版和安卓版的本地记录相互独立。先在网页版“设置 → 完整导出”，再在安卓版“设置 → 导入备份”。原有 JSON 格式和冲突处理规则保持不变。自定义背景保存在本机，需要在新设备重新选择；配置备份不含背景图片。

导出配置或结果图片时，安卓会让你选择保存位置。点“保存”并看到“文件已保存”后才算完成；取消选择不会保存文件。

## 更新与备份

新版通过 APK 分发，不在线下载规则。先导出配置备份，再打开同一发布者提供的新版 APK，直接覆盖安装。不要先卸载；卸载或清除应用数据会删除本机记录。

发布者必须沿用相同包名和签名，并递增 `android/AndroidManifest.xml` 的 versionCode。版本名称、界面提示及构建输出名称也需要同步更新。

签名材料放在 `output/android-signing/`。请把这个目录备份到自己控制的安全位置，包含密钥文件和凭据文件。不要把它发到群里或公开仓库。丢失签名后，新的安装包将无法直接覆盖原版。给用户分享 APK 即可，不要分享整个 output 文件夹。

## 本地构建

```powershell
./scripts/setup-android.ps1
node scripts/build-android.mjs
```

脚本使用官方 Temurin JDK 17、Android Platform 35 和 Build Tools 35。下载后验证发布方校验值。环境放在项目 `output/android-tools/`，不修改系统 PATH。安装包以独立目录构建，不替换网站 `dist/`，也不发布到云端。

```powershell
node --test tests/*.test.mjs
node scripts/build-android.mjs --qa
# Python 命令使用本机可用的 Python 3
python scripts/verify-android.py
```

`--qa` 另外生成一个独立测试探针，它不包含在正式 APK 内。正式包关闭 WebView 调试，不申请联系人、定位、相册全盘或存储全盘权限。文件选择和保存采用安卓系统文档选择器。

Android WebView 通过本地 HTTPS 资源拦截读取 APK 资产，不访问网站服务器。应用不加载远程网页到具有原生导出接口的 WebView 中；外部链接交给其他应用处理。网页版的 Service Worker 更新机制不会在 APK 内启用。

## 已发现问题与防复发

- Windows aapt2 的资产路径包含反斜杠。改由 JDK jar 写入 assets，并由 `verify-android.py` 拒绝任何反斜杠 ZIP 条目、校验资产字节，防止编译成功但手机白屏。
- 便携模拟器缺少标准 SDK 目录、运行库搜索路径及自己的用户配置目录。启动脚本为本项目补齐目录别名和进程级环境变量，不依赖或改写全局设置。
- 旧 WebView 83 不满足现有前端要求。应用启动检查内核版本，低于 107 时提示更新，不删除用户数据。

## 1.0.0 历史验证

正式 APK 已在 Android 15 / WebView 124 模拟器安装运行，关闭模拟器 Wi-Fi 和移动数据后测试。31 项单元测试、5 项安装包完整性检查及 15 项安卓运行检查通过。运行检查覆盖计算、拼音搜索、同名配置保存、JSON 导入导出、PNG 导出、自定义背景、系统深浅色、横竖屏、QQ 外链及同签名覆盖安装保留记录。界面截图已查看。

证据保存在 `output/android/qa/` 和 `output/android/package-checks.json`。覆盖安装测试使用相同版本安装包，不代表未来所有数据迁移已通过验证。没有连接真实手机；Android 8–14、厂商定制系统及 WebView 107 最低边界尚未实机验证。原有社区规则核验提示仍然适用。

测试脚本中，原生外链点击不等待网页导航（由外部应用接管）；Android CDP 连接使用 `noDefaults`；本地存储测试等待写入完成再重载。这些检查与发布包隔离，不开启正式包调试。
