# PMC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现可在本机运行的 PMC，逐条保留需求清单，并把未核实数据和未支持机制明确隔离。

**Architecture:** React 静态应用；计算、顺序模拟、保存和 UI 分离。使用冠军专用社区计算引擎并保留来源；正式数据须经过游戏核验，社区数据只用于标注清楚的试算。PWA 使用完整资源缓存，更新需用户确认。

**Tech Stack:** React、Vite、Smogon calc、pinyin-pro、浏览器本地存储、Node 内置测试。

执行说明：用户已要求直接制作，当前会话内执行。上述 superpowers 执行技能未安装，不因此中断，也不自动派生任务。先实现可独立测试的本地应用，再核查数据及复杂机制覆盖；不将未核验结果包装成正式版。

## 文件划分

- `src/data/catalog.json`：带来源的社区候选目录、中文词条和招式关系。
- `src/engine.mjs`：冠军伤害适配、点数验证、分布统计和回合事件。
- `src/storage.mjs`：配置、快照、版本化导入校验与冲突处理。
- `src/App.jsx`：计算、比较、配置库、场景、设置。
- `src/styles.css`：桌面与手机玻璃界面、主题、固定背景。
- `scripts/prepare-data.mjs`：下载固定来源、生成候选目录，不执行远端代码。
- `scripts/build-sw.mjs`：为构建内容生成离线缓存清单。
- `tests/core.test.mjs`：规则与数据持久化回归。
- `output/playwright/`：真实浏览器操作及截图证据。
