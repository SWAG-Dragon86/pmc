## 交付范围

本轮生成本地可运行应用与静态构建，保留原需求清单和用户背景图。完整游戏核验、全机制模拟和公开部署尚未完成，不能将本轮交付描述为正式版上线。

## 检查证据

- `tests/core.test.mjs`：冠军公式、点数上限、候选目录实例化、非法招式、重名及导入冲突、场景独立快照、HP 浮点取整、守住与范围修正、连击次数、麻痹降速、同速先手分支、倒下取消行动。
- `scripts/browser-qa.mjs`：真实 Chromium 中的搜索、开启试算、保存、双打、备份、主题、现场恢复、手机溢出、离线重载、导入和图片下载。
- `output/playwright/report.json`：浏览器实际运行的通过项目与控制台/网络错误。
- `output/playwright/` 中的截图：桌面、375px 手机、768px 平板、深色设置和结果 PNG。已实际打开检查首轮截图。
- 构建采用本地 Vite，生成 `dist/` 和资源版本化 Service Worker。

这些检查证明程序在所测范围内工作，不等于冠军数据和机制均已被游戏实测验证。

## 本轮纠错与防复发

| 问题 | 原因 | 修正 | 防复发检查 |
| --- | --- | --- | --- |
| npm 发行版没有冠军专用公式 | 发布包落后于上游源码 | 固定上游提交构建专用引擎 | 测试必须断言 generation 0 和冠军实际值公式 |
| ESM 构建访问 exports 报错 | 上游含 CommonJS 兼容逻辑 | 构建入口提供空 exports 兼容对象 | 本机 Node 导入 + 浏览器构建执行 |
| 单个目标仍被范围减伤 | 引擎克隆招式时丢失直接改动 | 通过 overrides 传递目标类型 | 守住/缺席成对回归用例 |
| 常用道具缺失 | 只读取冠军增量覆盖，漏掉合法继承项 | 按冠军引擎道具目录和覆盖规则筛选 | 气势披带、剩饭、生命宝珠、文柚果断言 |
| 形态别名遗漏 | 两个数据源命名和基础招式池标识不同 | 明确别名与继承关系 | 逐个候选配置实例化测试 |
| 百变怪默认配置不合法 | 假定所有宝可梦都有四个可选招式 | 允许空招式栏，仍保留四个位置 | 全目录默认配置合法性测试 |
| 残血重复取整 | 整数 HP 转百分比后浮点误差 | 边界精度修正 | 逐个整数血量往返断言 |
| JSX 构建失败 | 一处更新按钮回调少闭合括号 | 修正后格式化代码 | 生产构建作为交付门槛 |
| 浏览器运行版本不匹配 | 已安装 Chromium 与 Playwright 默认版本不同 | 使用已核实的本机可执行路径 | 实际浏览器启动与操作测试 |
| 中文词条覆盖不足 | 部分上游字典含尾逗号，不是严格 JSON | 只提取字典中的字符串键值，不执行翻译脚本 | 拼音搜索和中文词条浏览器检查 |
| 非法备份可能导致界面崩溃 | 场景目标和嵌套字段缺少形状检查 | 导入前验证目标、参与者标识和数值字段 | 畸形目标与能力点备份拒绝用例 |
| 未确认时预下载更新 | 使用了默认的 Service Worker 安装缓存方式 | 首次安装缓存，后续等待确认才取新版资源 | 独立更新服务器检查资源请求次数 |
| 同一范围招式中途变化影响其他受击者 | 顺序处理命中时重复读取变化后的攻击状态 | 同一招式使用出招时目标与攻击条件快照 | 范围修正与队友误伤回归 |
| 回合末先回复后天气伤害 | 简化结算顺序不正确 | 天气先结算，倒下后不再回复 | 沙暴击倒早于场地和道具回复用例 |
| 独立比较选择没有随现场保存 | 本地快照未包含勾选标识 | 将选择列表一并持久化 | 配置比较与恢复流程检查 |
