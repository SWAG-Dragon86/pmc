# PMC 1.4.0 安卓安装包

安装文件：`output/android/PMC-1.4.0-android.apk`。包名 `cn.pmc.calculator`，版本号 1.4.0，versionCode 8。要求 Android 8.0 及以上，Android System WebView 107 及以上。

已有 PMC 的手机直接覆盖安装，不要先卸载。沿用原签名；本次在 Android 15 模拟器覆盖 1.3.2，比较完整本地工作区、语言、名称别名和方向设置，确认记录保留。网页版与 APK 的本地记录仍各自保存，可通过完整备份转移。

## 本次内容

APK 使用当前 1.4 网页源代码，包含新的四席位结果界面、公开队伍联网更新、队伍／单只／场景分享图、分享码和二维码导入、五种语言、38 款精灵球主题。公开队伍在打开、回到应用、公开阵容页面每五分钟和手动点击时检查更新，按设备时间显示检查状态。

计算器和图片资源内置，可离线计算。联网更新需要连接网络；源站未发布新队伍时，应用显示检查时间，不伪造内容更新时间。

首次扫码会请求相机权限。系统授权窗口曾使待打开的相机提前关闭；本次修复授权窗口与应用后台事件的处理，允许授权后直接显示预览。已经打开的相机在退出扫码或切到后台时仍关闭。图片和分享码导入无需相机权限。
