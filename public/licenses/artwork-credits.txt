# Artwork credits and licenses

Updated 2026-11-26. Ordinary, regional and Mega forms all use Pokémon HOME full-body renders from [PokeAPI/sprites `sprites/pokemon/other/home`](https://github.com/PokeAPI/sprites/tree/c0542f7c51215d9672439012838c99f520596cbd/sprites/pokemon/other/home). All 350 catalog forms use that one set. Each file is trimmed to its opaque bounds and centered on a 512×512 canvas with 8% padding on the long side, so pixel sprites, portraits and vector icons are no longer mixed.

Image contents are copyright The Pokémon Company. The sprites repository's CC0 statement does not license those images. This is not official character or trademark clearance. The pinned commit and per-file checksums are in `src/data/sprites.json`. PokeAPI/sprites currently serves one HOME file for both Mega Meowstic forms; those two catalog entries stay separate.

18 type icons retain James Watkins / partywhale MIT terms. 37 Poké Ball icons use PokeAPI/sprites `sprites/items` at the same commit, enlarged 6× with nearest-neighbor sampling onto a 144×144 canvas. Those image contents are copyright The Pokémon Company; repository CC0 does not license them. The logo and app icons use the maintainer-supplied Rotom Pokédex image. Its contents are copyright The Pokémon Company. The default background is maintainer-confirmed original and retained unchanged; a standalone reuse license has not been selected.

Original code remains GPL-3.0-or-later. Do not describe this artwork change as official IP clearance, and do not apply an image copyright to the GPL code.

Retain source and modification notices when redistributing form images or exported cards. Exported PNG metadata carries the relevant credits, but social platforms may strip metadata; retain attribution separately when that happens. See [remaining gaps](ASSET_RIGHTS_REMAINING.md).

The 2026-10-23 publication used SpriteCollab frames and portraits plus The Artificial icons for these 350 files. Those form files have been replaced. The 37 Poké Ball icons later moved from Cobblemon Assets to PokeAPI/sprites item icons. Type icons and the background are unchanged. The logo later changed to the maintainer-supplied Rotom image; `0479洛托姆图鉴.png` keeps the earlier Emmuffin portrait. Repository screenshots still show the previous form images until they are recaptured.

All 350 catalog form image paths now have contributor permission records. The default background is maintainer-confirmed original and retained unchanged. Its standalone reuse license has not been separately selected; this is not an unknown third-party source.

The maintainer authorized removal of the unverified Strange Ball image and export theme on 2026-10-23. The current image inventory has no remaining files marked as lacking contributor reuse permission. All 37 remaining ball themes have permission records. Existing saved selections of the removed theme fall back to the default Poké Ball.

The eight screenshots were recaptured after the replacements and carry component credits in PNG metadata. They no longer contain the old species images. The removed Strange Ball is not shown in these captures.

The Artificial author statement says CC-BY without a version. The primary author download README confirms from-scratch art and share-with-credit permission; all 73 selected files match that archive. Preserve the actual statement rather than invent a CC-BY-4.0 or GPL grant.

Contributor permission records do not grant all underlying Pokemon character / trademark rights. The maintainer authorized historical-image cleanup and publication to GitHub and GitLab. This source history removes the 422 original artwork paths from all 18 earlier commits while preserving their non-image trees, then restores the current contributor-licensed replacements in the new publication commit. Historical commit IDs change. Platform-retained unreachable objects, caches and external clones may remain; this does not establish complete erasure or official character rights. No new signed APK is part of this source publication. See HISTORY-CLEANUP.md.
